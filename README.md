## Főbb funkciók

- **Valós idejű élő előnézet:** Ahogy gépelsz a bal oldali mezőben, a jobb oldalon azonnal megjelenik a formázott HTML eredmény.
- **Fájl mentése (.md):** Egyetlen kattintással letöltheted a megírt szöveget helyi `.md` fájlként.
- **Vágólapra másolás:** Gyors és kényelmes másolási gomb a tartalom azonnali megosztásához.
- **Egykattintásos törlés:** Megerősítéssel ellátott tisztítási lehetőség az új jegyzetekhez.
- **Teljesen reszponzív kialakítás:** Asztali nézetben 50-50%-os osztott képernyő, míg kisebb képernyőkön vagy mobilon automatikusan egymás alá rendeződnek a mezők.
- **Beépített szintaxis súgó:** Az oldal alján egy gyors referenciatáblázat segít eligazodni a legfontosabb Markdown jelölésekben.
